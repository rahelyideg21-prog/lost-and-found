# Lost and Found System

A web-based application designed to help users report and find lost items.

## Technologies Used
* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL (XAMPP)

## Setup Instructions
1. Clone the repository or download the source code.
2. Place the project folder inside your XAMPP `htdocs` directory.
3. Start **Apache** and **MySQL** in the XAMPP Control Panel.
4. Import the database file into phpMyAdmin.
5. Open your browser and go to: `http://localhost/lost-and-found/`
